NAI Utility Tool 1.3.0_fork.2.1 — 安装、覆盖升级与便携使用

覆盖旧版本（fork.2 首次迁移也使用此流程）
1. 保存正在编辑的内容，退出要升级的客户端。
2. 运行 NAI.Utility.Tool.1.3.0_fork.2.1.Setup.exe。
3. 旧版为 ZIP/7z 解压版时选“便携版”；已经用安装器安装则选“安装版”。
4. 选择旧版根目录：其中应直接包含 NAI Utility Tool.exe、bin 和 user。
   不要选择 bin 子目录，也不要在旧目录里面再新建一层 NAI Utility Tool。
5. 完成后仍运行原位置的 NAI Utility Tool.exe。

安装器仅替换程序文件；user/、output/、logs/、自定义资源和下载模型保留。
assets/ 与 models/ 只补充缺少的内置文件，不覆盖已有同名资源。
安装版卸载时保留用户数据与这些资源；彻底清理时请自己确认后删除剩余目录。

全新安装
选“安装版”后，默认安装到当前用户的 LocalAppData\Programs\NAI Utility Tool，
无需管理员权限，创建开始菜单和卸载入口；桌面快捷方式可选。
Windows 10/11 x64，运行时已包含；本轮安装和升级在 Windows 11 验证。

便携版
安装器选“便携版”，或把 ZIP/7z 解压到一个可写目录；运行根目录启动器。
便携安装不创建快捷方式或卸载登记。账户、设置、缓存与输出保持在程序目录。
ZIP/7z 不包含 user/、output/、logs/，覆盖解压不会覆盖这些数据；但解压工具
可能覆盖 assets/ 或 models/ 中同名内置资源，保留自改资源请使用安装器升级。
首次启动由应用创建目录，并从 assets/ 复制缺少的预设和通配词。

账户凭据使用 Windows DPAPI 绑定当前电脑和 Windows 用户；同机同用户升级可沿用。
复制到其他电脑或用户不保证能够解密已有凭据，需重新输入 API Token。
安装器不会强制终止客户端。遇到“文件正在使用”请先保存退出，然后重试。

fork.2.1 起的可选更新
帮助 → 检查更新：手动查看发行说明，选择新版本并下载，校验通过后确认关闭并安装。
更新仅来自 Andy-linux/NAI-Utility-Tool 的正式 GitHub Releases，不自动下载或安装。
安装器沿用当前根目录和便携／安装模式，等待客户端保存并退出。
fork.2 尚无更新入口，第一次升级到 fork.2.1 需按上面的手动流程操作。

----- English -----

Upgrade an older build in place (including the first migration from fork.2):
Save your work and close the destination client. Run Setup, choose Portable for an
extracted ZIP/7z edition (Installed for an existing registered install), then select
its ROOT folder containing NAI Utility Tool.exe and bin, not the bin subfolder.
Launch the same root executable after upgrading.

Setup replaces program files but keeps user/, output/, logs/ and existing resources.
Bundled assets/ and models/ files are installed only when absent. Uninstall keeps
user data and these resources. No process is force-terminated.

A new Installed edition uses the current user's LocalAppData\Programs folder and
creates Start menu/uninstall entries without requesting administrator privileges.
Portable mode writes only the destination folder, without shortcuts or registration.
ZIP and 7z are also portable. They contain no user/, output/ or logs/ entries, but
archive tools can overwrite same-named bundled assets/models. Use Setup to preserve
customized resource files. Missing defaults are seeded by the app on startup.

Windows 10/11 x64; runtimes are included. This installation batch is tested on Windows 11.
Encrypted credentials are tied to the Windows user and machine (DPAPI), not made
cross-machine portable by moving the folder. Re-enter credentials on another user/PC.

Optional updates from fork.2.1 onward:
Help > Check for updates lists stable releases from Andy-linux/NAI-Utility-Tool.
Choose a newer version, download and verify it, then confirm closing the client to
install. Updates are manual; Setup retains the root folder and installation mode.
The first fork.2-to-fork.2.1 upgrade requires running Setup manually once.

Silent deployment examples (close the client first):
Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /PORTABLE=1 /DIR="D:\NAI Utility Tool"
Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /DIR="D:\NAI Utility Tool"
